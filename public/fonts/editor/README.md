# Polices locales de l’éditeur

Fichiers utilisés dans l’aperçu CSS et le rendu libass, sans chargement externe à l’usage.

- DejaVu Sans/Serif/Sans Mono : fichiers du paquet Debian fonts-dejavu-core du conteneur de montage, licence dans LICENSE.txt.
- Anton : https://github.com/google/fonts/tree/main/ofl/anton — Anton-Regular.ttf, licence anton-OFL.txt.
- Bebas Neue : https://github.com/google/fonts/tree/main/ofl/bebasneue — BebasNeue-Regular.ttf, licence bebasneue-OFL.txt.
- Oswald : https://github.com/google/fonts/tree/main/ofl/oswald — Oswald[wght].ttf, licence oswald-OFL.txt.

Trois dernières familles récupérées du dépôt officiel Google Fonts le 22 octobre 2026, noms locaux simplifiés sans modifier les fichiers. Chaque licence est distribuée avec la police concernée.
